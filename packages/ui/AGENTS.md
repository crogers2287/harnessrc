# Required shared-component design workflow

Follow `../../docs/UI_DESIGN.md` and the design-skill workflow in `../../apps/web/AGENTS.md` before creating or reviewing shared UI components. Read all three referenced SKILL.md files, then applicable references. Use semantic HTML, semantic theme tokens, accessible focus and state handling, and the project's 48px mobile hit-area default. Preserve the React PWA stack and render only supported adapter actions. Verify components inside the actual application at phone and desktop widths; do not claim native-device validation from browser emulation.
